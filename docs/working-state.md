## 场景与体型修复

水生形象此前同时受画布留白和额外缩放影响，幼体可见轮廓偏小。本轮改了可见范围元数据、绘图与点击框分离、嘴部投影及移动边界。

体型修复涉及 `style.css`、`companion-art.js`、`companion-growth-art.js`、`companion-device-ui.js`、`companion-roam.js`；没有更改成长阶段和成长数据。

`companion-scenes.js/resolveCompanionDisplayScene()` 现统一决定实际场景，供主界面、掌机、底栏与漫游共用。选择场景会真正退出庭院等生活地点或装修显示；保存装修会进入装修小窝。上述切换保留原有家具、库存、农田和旅行数据，菜单返回改为“返回场景”。

14 个原生场景保留完整原画，不额外叠加小窝门柜。原生卧室原本已有床窗柜，因此也移除了重复的悬空门柜；自定义装修小窝继续保留原有生活设施及装修遮挡处理。

`companion-aquatic.js` 为独立室外场景增加自然水域；荷塘与海滩使用原画的水面，室内仍无缸自由移动，原来的五个生活地点水域坐标保留。远景荷塘窄水带按其透视适配体型，44px 触摸区独立保留；不能把室内体型尺寸推广到所有远景场景。

390px 宽的标准室内及草地小池中，幼蛙可见轮廓约由 33×20px 变为 69×41px。最终单独复现了用户的“meadow + home + 未装修”室外组合，并实际查看草地、卧室、荷塘和庭院手机截图。
