# Frog pixel sample A

`frog-pixel-a-v1.png` is original raster artwork generated with the built-in OpenAI image generation tool. The generated PNG is used unchanged (1774 × 887, transparent background). It is not a procedural reconstruction of the reference.

The user selected the fine pixel-art A direction. This sample applies only to the adult frog. `src/companion-frog-sprite.js` crops four expressions from the atlas; CSS supplies breathing, blinking, interaction timing and sleep. Crops share a 448 × 364 viewport and the same foot baseline. Tint filters preserve the cream belly and dark outline while keeping existing skin/accent controls usable.

## Generation prompt

Use case: stylized-concept / production pixel-art sprite sheet. Reference image role: character identity and pixel-art style reference. Use ONLY the GREEN FROG IN THE TOP LEFT, under A, from the reference. Preserve that frog's appealing pixel silhouette and proportions, large rich dark brown eyes with tiny bright glints, pale yellow cream round belly, soft pink cheeks, squat body, short folded back legs and tiny front toes, mossy lime green palette and dark olive-brown pixel outline. IGNORE the smooth right column completely. Generate one production-ready TRANSPARENT PNG atlas with exactly FOUR equally sized SQUARE cells in a strict 2 by 2 grid. No visible grid lines. All four frames depict the SAME adult frog at the EXACT same size and same front-facing sitting position, same body pixels and foot baseline. Only change facial expression. Each frog is fully contained inside its own cell, centered, feet baseline at 86% of its cell height, topmost head pixel at 14% of cell height, character width about 72% of cell width. Consistent pixel alignment and limited palette across all frames. TOP LEFT: neutral idle, friendly open eyes, tiny closed smile. TOP RIGHT: delighted smile, eyes curved closed like cheerful inverted U shapes, mouth tiny smiling. BOTTOM LEFT: eating, open eyes, small dark open mouth with a tiny pink tongue, no food props. BOTTOM RIGHT: peaceful sleeping, closed relaxed horizontal curved eyelids, tiny relaxed mouth. The feet, body, belly, outlines, color, scale and position must be identical in all four frames. This must look like beautifully hand-authored small pixel game art enlarged with nearest-neighbor scaling, ~80x80 logical sprite per cell, crisp pixel clusters, gentle 3-tone shading, no smooth vector curves, no 3D, no blur, no painterly texture. Strongly match the TOP LEFT reference frog rather than inventing a different mascot. Background must be truly transparent, including all margins and all gaps between sprites. No cream/white background, no checkerboard drawn into the image, no shadows outside character, no ground, no text, no labels, no watermarks, no extra objects.
